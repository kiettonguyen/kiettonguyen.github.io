Project scope module

A course module that teaches staff to scope a project before they start it.

Client
An Australian university
Course
Project work and financial compliance
Role
Learning design, writing, build
Platform
Canvas LMS

Brief

Staff were starting projects with no agreed scope. The module had to make scoping practical.

Approach

One realistic example runs through every page. Each idea is shown in use, then practised on a new case.

Note

Recreated with a new scenario and visuals, to protect the client's content.
