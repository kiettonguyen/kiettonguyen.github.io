The brief

This is the first module of a course on project work and financial compliance, made in Canvas for an Australian university. It teaches people to define a project's scope before the work starts, and to keep using it once the work is under way.

One project, start to finish

Every sheet follows the same example, a council team launching a community newsletter. Learners see each idea used on that project before they try it themselves, so nothing stays abstract for long.

The newsletter's goal, deliverables, exclusions and limits come together on sheet 1.4 as a one-page scope statement, signed off by the sponsor. The later sheets build their charts and resource lists straight from it.

Practice with consequences

Sheet 1.4 ends with Hold the line. It's week six, the scope is agreed, and six requests land on your desk. Each answer moves the budget, the team's hours and the delivery date, so a few friendly yeses quickly add up.

Every request has an answer in the scope statement. That's the lesson the whole module builds to.

About this version
